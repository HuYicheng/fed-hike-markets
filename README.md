# 美联储加息与三地股市

这个网站把 1987 年 6 月以来美联储 8 段已经走完的加息放在一起比较。每一段都看港股、美股、A 股四件事：
- 是涨是跌；
- 哪些行业和股票跑赢；
- 跟着什么因素走；
- 数据全不全。

## 怎么看

- **网页版：** https://claude.ai/artifact/27edgtJhGxsFQLs6WT8Tbw ，是私有页面，只有本人能打开。
- **本地打开：** 下载 `index.html`，直接用浏览器打开。
  - 整个网站就是这一个文件，数据都在里面，不需要联网。
  - 网址后面加 `#rise`、`#sector` 这样的标记，可以直接打开某一页。

这个仓库是私有的，没有开 GitHub Pages。个人账号的 Pages 网页对所有人公开，私有仓库也一样。

## 内容

一共 11 页：
- 首页
- 涨跌
- 指数走势
- 加息初期
- 行业
- 个股
- 推动力
- 2003–07 港股
- 这次加息
- 数据覆盖
- 怎么算的

每页标题都写成“短名：这一页回答什么”，并且可以切换港股、美股、A 股。

## 数据和授权

- 个股的涨跌来自 WRDS 授权的数据，只供本人使用，不要公开：
  - 美股用 CRSP；
  - 港股用 Compustat Global，用新浪、腾讯、Yahoo 补缺；
  - A 股用 Baostock，分红和行业用 Compustat。
- 利率来自 FRED。
- 指数来源：
  - 恒指 2013 年以前用 Yahoo，以后用新浪；
  - 国企指数、标普 500、道琼斯工业、罗素 2000 用 Yahoo；
  - 纳斯达克综合用纳斯达克交易所的官方收盘价（经 FRED）；
  - 上证综指、深证成指、上证 50、沪深 300、中证 500、创业板指、科创 50、恒生科技用新浪。
- 核对：
  - 除恒生科技和罗素 2000 外，每个指数都用第二个来源逐日核对过点位。
  - Yahoo 有个别日子的数是错的：纳斯达克 2004 年 9 天，上证综指 1997、1999 年 4 天，恒指 2023-08-25。这些日子另用腾讯或官方收盘价核对过，网站用的是对的数据。
- 指数只画它正式发布以后的加息段。发布日期和出处见原项目 `data/raw/indices_more/launch_dates.tsv`。

## 怎么生成的

`build/` 里是生成程序的副本：
- `91_build_site.py`
- `site_template.html`
- `shots.py`（检查程序）
- `92_fetch_more_indices.py`、`93_check_more_indices.py`（下载和核对“指数走势”页的指数）

生成程序在原项目里读三份报告和综合报告的结果表，算出网页上的每个数字。生成时有两项核对，对不上就停下：
- 17 个关键数字与综合报告一致；
- 每条指数走势线的终点与结果表一致。

生成后，每一页都在电脑和手机宽度、浅色和深色下打开检查。2026-10-24 共 44 次检查，没有脚本错误、没有排版溢出，图都画出来了。

以下明细没有放进网站，仍在原来的 PDF 报告里：
- 各行业的回归明细；
- 扩展因子的回归表；
- 3 个月窗口；
- 港股南向资金和事件研究的明细表。
